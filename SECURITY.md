# Security policy

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting:

→ [Report a vulnerability](https://github.com/thedavedavies/ledger/security/advisories/new)

This opens a private advisory thread visible only to you and the maintainer. Don't open a public GitHub issue or pull request describing the vulnerability.

If you can, include:

- A description of the issue and where it lives in the code
- Steps to reproduce
- Affected version (commit SHA is fine)
- Any suggested fix or workaround

## What to expect

This is a small project with a single maintainer. Security reports take priority over feature work, but response times depend on real life. You'll get an acknowledgement as soon as I see the report.

## Scope

In scope: the Community Edition (this repo).

Out of scope:

- Self-hosted instances exposed to the public internet without authentication. The README warns against this; misconfiguration of a deployment is not a vulnerability in the code.
- Issues that only affect modified forks.

## Coordinated disclosure

I'll work with reporters to agree a disclosure timeline. The goal is a fix and advisory within 90 days of confirmation. Reporters who'd like credit will be credited in the advisory; reporters who'd rather stay anonymous can.
